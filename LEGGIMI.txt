PORTFOLIO EXTERNAL REFERENCE - COME AGGIORNARE FOTO E TESTI

Le foto del sito sono nella cartella "foto", una cartella per progetto:

  foto/00_home        le 4 immagini dei riquadri della home (01 Studio, 02 Urban, 03 Interior, 04 Art)
  foto/01_studio/...  le immagini delle pagine Studio
  foto/02_urban/...   Urban & Architecture
  foto/03_interior/.. Interior
  foto/04_art/...     Art & Collectible Design

AGGIUNGERE O SOSTITUIRE UNA FOTO
1. Su GitHub apri la cartella del progetto (es. foto/03_interior/02_alkimia).
2. Add file > Upload files, trascina la foto (JPG, PNG o TIFF, anche ad alta risoluzione, max 25 MB).
3. Chiamala con il numero della posizione: 05.jpg diventa la quinta foto.
   Se esiste già 05.webp, la nuova foto la sostituisce.
4. Commit changes.
In 2-3 minuti GitHub converte la foto (WebP, lato lungo 2400 px, mai ritagliata),
aggiorna la miniatura e ripubblica il sito. Poi ricarica la pagina con Ctrl+F5 (Mac: Cmd+Shift+R).

TOGLIERE UNA FOTO
Apri il file .webp nella cartella del progetto, menu ... > Delete file > Commit changes.

ORDINE
Le foto si vedono in ordine di nome: 01, 02, 03... La 01 è la copertina del progetto.

NOTE
- Non rinominare le cartelle: il nome dice al sito a quale progetto appartengono le foto.
- La cartella "miniature" e il file "foto.js" si aggiornano da soli: non toccarli.
- Per seguire l'aggiornamento: scheda "Actions" del repository (pallino verde = fatto).

MODIFICARE I TESTI DI UN PROGETTO
Ogni cartella progetto contiene testo.txt. Su GitHub aprilo, clicca la matita (Edit), modifica e Commit changes.
In alto ci sono le righe della scheda, nella forma "Nome: valore":

  Title: Plaza Mahou                 titolo del progetto
  Place: Madrid, Spain, 2025         riga grigia sotto il titolo
  Category: Restaurant               sottocategoria (Restaurant, Hotel, Retail...)
  Tags: Hospitality, Madrid          tag separati da virgola
  Location: Madrid, Spain            da qui in giù: le righe della scheda,
  Typology: Restaurant               nell'ordine in cui le scrivi
  Area: 1000 m²                      (puoi aggiungerne o toglierne: Client, Collaboration...)
  Status: Built

Poi UNA RIGA VUOTA, poi il testo. Una riga vuota tra due paragrafi.
Per il grassetto: **parole in grassetto**.

AGGIUNGERE UN PROGETTO NUOVO
1. Apri la sezione (es. foto/03_interior) > Add file > Create new file.
   Nel nome del file scrivi: 42_nome-progetto/testo.txt
   (lo "/" crea la cartella; numero = posizione, poi il nome senza spazi né accenti).
   Scrivi la scheda come sopra e Commit changes.
2. Entra nella nuova cartella > Add file > Upload files, trascina le foto (01.jpg, 02.jpg...).
3. Commit changes. Il progetto compare nell'indice, nella sua categoria, dopo 2-3 minuti.
Una categoria nuova (es. Category: Wellness) crea da sola un nuovo gruppo.
Per togliere un progetto: cancella la sua cartella (tutte le foto e testo.txt).

Le pagine Studio (Our Story, Approach, Awards...) hanno impaginazioni speciali e restano in index.html:
per modificarle chiedi a Claude.

NASCONDERE UN PROGETTO
Nel testo.txt del progetto aggiungi, sotto la riga Tags:, la riga
  Visible: no
Il progetto sparisce dal sito (indice, elenco, frecce). Per farlo riapparire: Visible: yes (o cancella la riga).

PROTEGGERE UN PROGETTO CON PIN
1. Una volta sola: GitHub > Settings > Secrets and variables > Actions > New repository secret
   Name: PORTFOLIO_PIN   Secret: il codice (es. 4827). Vale per tutti i progetti protetti.
2. Nel testo.txt del progetto aggiungi, sotto la riga Tags:, la riga
  PIN: yes
Il progetto resta nell'elenco con la copertina sfocata e la scritta Confidential;
per aprirlo serve il PIN (il browser lo ricorda finché la finestra resta aperta).
Per togliere la protezione cancella la riga PIN: yes.
Se il segreto PORTFOLIO_PIN non c'è, il progetto con PIN viene nascosto per sicurezza.
Per cambiare il PIN: modifica il segreto, poi Actions > Aggiorna foto del portfolio > Run workflow.
Nota: il PIN protegge il sito; le foto restano comunque nel repository pubblico.
